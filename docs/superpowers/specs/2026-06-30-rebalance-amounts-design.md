# 再平衡金额展示设计

- 日期：2026-06-30
- 状态：已确认
- 范围：总览页、分析看板、资产负债录入提示、再平衡 API

## 背景

当前再平衡预警只展示目标占比、当前占比和偏离比例。用户能够判断某项资产超配或低配，但无法直接知道当前金额、目标金额以及需要增持或减持的金额。

此外，现有计算以净资产为分母。车辆等不参与投资组合再平衡的资产仍会影响比例，负债也会改变资产配置口径。新设计改为只用用户明确纳入再平衡的资产作为计算基数。

## 目标

1. 把比例预警转换为可行动的金额建议。
2. 允许用户通过目标占比 `0%` 排除车辆等不参与再平衡的资产。
3. 确保参与项目标占比合计必须为 `100%`，不做静默归一化。
4. 在总览页和分析看板使用同一套后端计算结果。
5. 保留现有偏离阈值、排序和历史快照语义。

## 非目标

1. 不实现自动交易或一键调仓。
2. 不计算税费、交易费用、滑点或最小交易单位。
3. 不增加独立的“是否参与再平衡”数据库字段。
4. 不按资产分类自动排除车辆、房产等项目。

## 参与规则

只处理 `type = asset` 的项目：

- `target_ratio > 0`：参与再平衡。
- `target_ratio = 0`：排除，不进入分母，不产生预警。
- `target_ratio` 未设置：排除，不进入分母，不产生预警。
- 负债：始终不参与资产再平衡。

参与资产总额为所有参与项当前折算金额 `amount_base` 的合计。被排除资产金额仅用于界面说明，不进入任何比例或目标金额计算。

## 成员边界

目标占比沿用录入页现有的成员维度语义：每位成员拥有独立的参与资产池，每位存在参与项的成员，其目标占比均必须合计为 `100%`。当前只有一位成员时，结果与家庭级单一资产池完全一致。

总览摘要中的参与金额和排除金额可以按家庭汇总，但每个资产的当前占比、目标金额和调整金额均以所属成员的参与资产总额为分母。API 返回成员配置明细，避免多成员时把两组各自为 `100%` 的目标错误判断为 `200%`。

## 配置有效性

每位成员的参与项目标占比之和必须等于 `100%`。

- 后端使用 `Decimal` 对持久化目标占比精确求和，并与 `Decimal("100")` 比较。
- 等于 `100%`：执行比例、目标金额和调整金额计算。
- 不等于 `100%`：返回配置无效状态、当前合计和距离 `100%` 的差额。
- 不允许前端或后端静默归一化。录入页现有的“一键归一化”必须由用户明确触发，并且只能调整目标占比大于 `0%` 的参与项，不能把 `0%` 或未设置项目重新纳入。
- 配置无效时不返回调仓建议。

如果没有参与项，返回“尚未配置参与再平衡的资产”；如果参与资产总额为零，返回“暂无可计算金额”。这些属于正常业务状态，不作为 HTTP 错误。

## 计算公式

对每个参与项：

```text
当前占比 = 当前金额 ÷ 参与资产总额 × 100%
目标金额 = 参与资产总额 × 目标占比 ÷ 100%
调整金额 = 目标金额 - 当前金额
偏离度   = 当前占比 - 目标占比
```

- `调整金额 > 0`：建议增持。
- `调整金额 < 0`：建议减持。
- `偏离度 > 0`：超配。
- `偏离度 < 0`：低配。
- `abs(偏离度) >= 再平衡阈值` 时进入预警结果。

金额计算在后端使用 `Decimal`，API 输出沿用现有数字格式。界面按基准币种格式化为两位小数。

## 示例

当前数据中：

- 汽车：`¥120,000`，目标占比 `0%`，被排除。
- 参与资产总额：`¥3,283,426.73`。
- 美股股票当前金额：`¥1,259,717.24`。
- 美股股票目标占比：`23%`。
- 目标金额：`¥755,188.15`。
- 调整金额：`-¥504,529.09`。

界面显示“建议减持 `¥504,529.09`”。

## API 设计

`GET /api/v1/analytics/rebalance` 从数组调整为结构化结果：

```json
{
  "valid": true,
  "reason": "ok",
  "participating_amount": 3283426.73,
  "excluded_amount": 120000,
  "excluded_count": 1,
  "allocations": [
    {
      "member_id": 1,
      "member_name": "自己",
      "participating_amount": 3283426.73,
      "target_ratio_total": 100,
      "target_ratio_gap": 0,
      "valid": true
    }
  ],
  "items": [
    {
      "id": 1,
      "member_id": 1,
      "member_name": "自己",
      "name": "美股股票",
      "target_ratio": 23,
      "current_ratio": 38.36,
      "deviation": 15.36,
      "current_amount": 1259717.24,
      "target_amount": 755188.15,
      "adjustment_amount": -504529.09,
      "status": "超配"
    }
  ]
}
```

`reason` 取值：

- `ok`
- `no_participating_assets`
- `invalid_target_total`
- `zero_participating_amount`

每个成员配置中的 `target_ratio_gap = 100 - target_ratio_total`。正数表示尚缺，负数表示超出。

所有现有前端消费者必须与 API 变更同时更新，不保留重复的旧数组响应。

## 总览页

再平衡预警标题下增加摘要：

```text
参与再平衡资产 ¥3,283,426.73 · 已排除 1 项 ¥120,000.00
```

采用“行动优先”卡片：

1. 第一行：资产名称和“超配/低配”徽标。
2. 主信息：建议增持或减持金额。
3. 次信息：当前占比、目标占比、偏离百分点。
4. 底部：当前金额和目标金额。
5. 保持现有最多展示 6 条和按绝对偏离度排序的规则。

任一成员的目标配置无效时，用黄色提示替代全部卡片列表：

```text
自己：目标占比合计为 97%，尚缺 3%。请修正为 100% 后查看调仓建议。
```

提示提供“去资产负债录入修正”入口。配置有效但没有超过阈值的项目时，继续显示“当前配置均在阈值范围内”。

## 分析看板

再平衡提醒表格调整为：

1. 资产
2. 成员
3. 调整建议
4. 当前金额
5. 目标金额
6. 当前占比
7. 目标占比
8. 偏离
9. 状态

“调整建议”显示“增持/减持 + 金额”。小屏幕沿用现有横向滚动，不新增独立移动端组件。

目标配置无效、没有参与项或参与资产总额为零时，与总览页使用同一套业务状态文案。

## 资产负债录入

目标占比字段增加说明：

```text
填写 0% 或留空表示该资产不参与再平衡计算。
```

不增加新的开关或字段。现有 `target_ratio` 继续作为唯一配置来源。

## 数据流

1. 后端从选定日期范围内的最新每日快照读取持仓。
2. `compute_rebalance_items` 按成员筛选参与项并汇总各自的参与资产总额。
3. 后端逐成员校验目标占比合计。
4. 配置有效时计算比例和金额，并按现有阈值筛选、排序。
5. API 返回结构化状态和预警项目。
6. 总览页和分析看板直接展示 API 结果，不在前端重复金额计算。

## 兼容性

- 不需要数据库迁移。
- `target_ratio = 0` 的语义从“目标为零并产生超配预警”调整为“排除再平衡”。
- `target_ratio` 未设置仍保持不参与计算。
- 多成员家庭沿用录入页现有的“每位成员各自配置 100%”语义。
- 现有“一键归一化”保留为显式用户操作，但只处理目标占比大于 `0%` 的参与项。
- API 响应结构会变化，但仅由仓库内前端消费，后端与前端必须原子更新。

## 测试

后端：

1. `0%` 和未设置目标占比的资产不进入分母。
2. 负债不参与计算。
3. 任一成员目标占比合计不是 `100%` 时返回无效状态和成员差额，`items` 为空。
4. 参与资产总额、当前金额、目标金额和调整金额正确。
5. 增持、减持、超配和低配方向正确。
6. 现有阈值边界与绝对偏离度排序保持不变。
7. 日期范围仍使用范围内最新快照。
8. 多成员分别以各自参与资产总额计算，不互相污染分母。

前端：

1. 总览页展示行动优先卡片和参与资产摘要。
2. 分析看板展示新增金额列。
3. 目标合计无效时显示修正提示且不显示金额建议。
4. 没有参与项、参与金额为零以及无预警时显示对应空状态。
5. 目标占比输入说明明确 `0%` 和留空的排除语义。
6. 用户主动触发归一化时不修改 `0%` 或未设置的排除项。

## 验收标准

1. 车辆目标占比设为 `0%` 后，不影响其他资产当前占比和目标金额。
2. 参与项目标合计为 `100%` 时，每条预警都能看到当前金额、目标金额和增减金额。
3. 参与项目标合计不为 `100%` 时，系统明确提示差额且不输出调仓金额。
4. 总览页和分析看板对同一快照展示完全一致的比例与金额。
5. 现有再平衡阈值、排序和历史日期筛选没有行为回归。
